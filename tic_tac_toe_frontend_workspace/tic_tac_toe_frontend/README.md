# Tic Tac Toe Flutter App

A modern, minimalistic Tic Tac Toe game implemented in Flutter for mobile devices.

## Features

- Clean, intuitive 3x3 game board UI
- Player vs Player mode (same device)
- Win/draw detection and notification
- Game reset functionality
- Simple main menu
- Light, modern design with custom color theme

## Getting Started

1. Install [Flutter](https://flutter.dev/docs/get-started/install) if it's not installed.
2. Clone this repository.
3. Run `flutter pub get` to install dependencies.
4. Use `flutter run` to launch the app on an emulator or device.

## Folder Structure

- `lib/main.dart` — All app logic and UI
- `pubspec.yaml` — Project configuration and core dependencies

## Minimal Tech

- Flutter SDK (no third-party packages required)
